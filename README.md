# StudySpace

A clickable prototype of **StudySpace**, a study room finder for Metro State students. Built for ICS 377 (Interaction Design with User Experience) by Group 1: Brian Kayega, Mai Moua and Mai Nhia Vang.

This is the web version of design **Concept C** from our Figma prototype.

## What you can do

- Search rooms, or tap a quick filter such as Quiet or Whiteboard
- Filter by building, group size, noise level and amenities
- Save rooms with the heart
- Pick a day and an open hour, then book with a Star ID (format: `ab1234cd`)
- See or cancel your bookings under Profile

## Notes

- Rooms, schedules and availability are sample data. Building names are real; room details are made up.
- Bookings and saved rooms are stored only in your own browser (localStorage).
- Everything is in one file, `index.html`: plain HTML, CSS and JavaScript with no build step.

## Run it locally

Open `index.html` in any browser.
